# OCR для СТС / VIN

Распознавание работает через OpenAI Responses API.

Версия v36 специально настроена под фотографии российских СТС:
- передаёт модели полный кадр и 3 увеличенных перекрывающихся фрагмента;
- использует отдельный улучшенный полный кадр;
- ищет VIN в строке «Идентификационный номер (VIN)» и повторе в «Кузов (кабина, прицеп) №»;
- собирает VIN, даже если OCR вставил пробелы или разделители;
- проверяет стандарт VIN (17 символов, без I/O/Q);
- сохраняет кандидатов VIN и технические ошибки в Railway logs;
- использует Structured Outputs JSON Schema, а при проблеме делает резервный запрос.

Для работы нужен `OPENAI_API_KEY` в Railway Variables.
Можно переопределить модель через `OPENAI_VISION_MODEL`.

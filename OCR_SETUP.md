# Локальное распознавание СТС / VIN

Версия v41 больше не использует OpenAI или DeepSeek для OCR. Распознавание выполняется локально на Railway через PaddleOCR.

Распознаются:
- VIN — с проверкой формата 17 символов;
- госномер — с проверкой формата российского регистрационного номера;
- год выпуска — с приоритетом строки «Год выпуска».

Используются лёгкие PP-OCRv5 mobile-модели: детектор `PP-OCRv5_mobile_det` и восточнославянская модель распознавания `eslav_PP-OCRv5_mobile_rec`. Официальная документация указывает, что mobile detector предназначен для эффективного запуска, а восточнославянская модель поддерживает русский, английский и цифры.

Первый запуск после установки может скачать модели. Кэш направляется в `/data/.paddlex`, если Railway Volume смонтирован в `/data`, поэтому после первого скачивания модели должны сохраняться между перезапусками.

Фото не отправляется во внешний OCR API.

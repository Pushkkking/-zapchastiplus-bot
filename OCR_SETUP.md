# Распознавание VIN и госномера по фотографии

v30 добавляет распознавание фотографии через OpenAI Responses API. Ключ хранится только в Railway Variables и не попадает в GitHub.

## Railway Variables

Добавьте:

- `OPENAI_API_KEY` — ваш API key OpenAI
- `OPENAI_VISION_MODEL` — необязательно; по умолчанию `gpt-4.1-mini`

После этого клиент в «Добавить автомобиль» может нажать `📷 Сфотографировать VIN` и отправить фото.

Бот покажет распознанные VIN/госномер и попросит подтвердить сохранение. Если распознать данные не удалось, можно ввести VIN вручную.

Важно: распознавание не считается гарантированно правильным. Клиент всегда видит результат до сохранения.

# Постоянное хранение базы на Railway

Эта версия бота поддерживает Railway Volume для SQLite.

## 1. Добавь Volume

В Railway открой сервис бота:

**Service → Volumes → Add Volume**

Укажи Mount Path:

`/data`

Размер можно выбрать с запасом под текущую базу. Для SQLite обычной CRM такого размера более чем достаточно.

## 2. Переменная DB_NAME

Обычно её можно **не создавать**. Код сам использует:

`/data/zapchasti_plus.db`

Если в Railway уже есть переменная `DB_NAME`, проверь, чтобы она указывала именно на файл внутри Volume, например:

`/data/zapchasti_plus.db`

## 3. Первый запуск после подключения Volume

Если в старой рабочей директории Railway уже есть `zapchasti_plus.db`, а в `/data` ещё нет базы, бот автоматически скопирует старую базу в `/data` при первом запуске.

Это позволяет сохранить существующих клиентов, автомобили, заявки и заказы.

После этого `/data/zapchasti_plus.db` становится основной базой.

## 4. В дальнейшем

При изменении кода, GitHub Push и новом деплое Railway будет обновлять код, но база находится отдельно на Volume.

**Не удаляй Volume**, если хочешь сохранить данные клиентов.

## Важно

Перед первым подключением Volume желательно убедиться, что текущий бот действительно работает и текущая база содержит нужные данные.

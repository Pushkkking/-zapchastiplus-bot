# Запчасти+ — v22

Добавлено:
- списание кешбэка при оформлении заказа (до 50% стоимости);
- возврат списанного кешбэка при отмене заказа;
- начисление нового кешбэка только на фактически оплачиваемую сумму;
- журнал операций кешбэка в SQLite;
- кнопка «💳 Моя карта»;
- персональный QR-код карты клиента;
- QR открывает Telegram deep-link; при сканировании владельцем бота показывается карточка клиента, уровень и доступный кешбэк;
- автоматическая миграция существующей БД и перенос исторически начисленного кешбэка в журнал;
- сохранена работа Railway Volume `/data`.

## Переменная Railway
Можно добавить необязательно:
`BOT_USERNAME=ZapchastiPlusTogliattiBot`

Если переменную не добавить, используется это же имя бота по умолчанию.

## Логика кешбэка
- списать можно максимум 50% стоимости заказа;
- доступный баланс списывается только после подтверждения заказа;
- при отмене заказа списанная сумма возвращается;
- при выдаче заказа новый кешбэк рассчитывается от суммы после списания кешбэка;
- старые заказы и накопленный кешбэк не удаляются.
